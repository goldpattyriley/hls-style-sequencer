# Project provenance

This repository is an independent HLS-style recreation developed for this project. It is not an official Hinkle's Lighting Sequencer distribution and does not bundle the original HLS executable or native source. HLS is used descriptively to identify the authoring workflow being studied.

- `outputs/windows7/source`: application and test source developed for this recreation, using .NET Framework libraries. Original HLS, xLights and Vixen code is not bundled.
- PNG images: captures of this project's own native WinForms controls rendered offscreen.
- `demo.wav`: the synthetic metronome/demo audio used by the local samples. No commercial song is included.
- `.hlsr`, `.hlsrlib`, `.hlsrpreview` and `.fseq` examples: sample channel maps, handcrafted effects and rendered values generated in this project.
- Historical HLS evidence is linked from the guides; original tutorial videos and source archives are not redistributed here.
- .NET Framework reference assemblies are build inputs obtained separately from Microsoft's reference package; they are not bundled.

This private testing publication does not select an open-source license.
